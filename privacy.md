# CricHit — Privacy Policy

Last Updated: September 2026

## 1. Data We Collect
* **Discord User IDs:** Stored to maintain user profiles, balances, and user squads.
* **Server IDs:** Processed to execute commands in channels.
* **Usernames:** Displayed in user's playing xi's, squads, leaderboards, etc.

## 2. How We Use Data
Collected data is strictly used to process game mechanics and player progression. We do not sell, trade, or share user data with third parties.

## 3. Data Storage & Security
Data is securely stored in local SQLite databases managed by the bot developers.

## 4. Data Deletion Requests
To request a complete deletion of your profile and data, contact the developers (`joe_root66` or `phasmocorrupted`) directly via Discord.
